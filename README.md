# 🧬 LifeSpan Test — 健康寿命预测测试

一个类似 MBTI/SBTI 风格的**健康寿命预测 H5 测试**，通过 40+ 道科学的生活方式评估题目，给出用户的「预计健康寿命」「健康人格类型」「逆天改命建议」。

## ✨ 特性

- **41道科学测试题** — 涵盖睡眠、饮食、运动、心理、健康指标、身体信号、生活习惯 7大维度
- **25种健康人格类型** — 如"自律龙型""佛系海龟型""涅槃凤凰型"等
- **科学依据** — 每道题基于公开流行病学文献（Framingham、Blue Zones、WHO、Lancet 等）
- **量化改善建议** — "改善XX → 多活X年"
- **纯前端** — 零后端，零依赖，Cloudflare Pages 直接部署
- **移动端适配** — 响应式设计，手机/平板/桌面均可使用

## 🚀 部署

### Cloudflare Pages

1. Fork 本仓库
2. 在 Cloudflare Pages 中创建项目
3. 连接 GitHub 仓库
4. 构建设置：框架预设 `None`，输出目录 `/`
5. 部署完成

### 本地预览

```bash
# 方式一：直接打开
open index.html

# 方式二：本地服务器
npx serve .
# 或
python3 -m http.server 8080
```
